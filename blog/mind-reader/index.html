How it works

The predictor builds a frequency table from your recent picks. Given the context of your last 1-4 choices, it looks up what you did next in similar situations and bets on the most likely side. After about 20 picks it typically reads you 60-70% of the time

This is the same core idea behind Jeffy, an open-source text classifier. Instead of tracking left/right patterns, Jeffy maps text into a high-dimensional embedding space and trains logistic regression on top. Same principle: find patterns in how humans make choices, then predict them

Jeffy ships 68 pretrained classifiers for text, game state, and numeric features. They run on CPU in under 80ms, no GPU or API keys needed. Install with pip install jeffy-classify and start classifying in 3 lines of code
