Jeffy takes a different approach. Logistic regression on frozen embeddings. No LLM, no prompt, no parsing. Same input always gives the same output. The Jeffy node brings 70 pretrained classifiers into n8n as a dropdown

The problem with n8n's built-in classifier

The built-in node sends your text to an LLM and parses the response as JSON. Here's what people run into

"Failed to parse LLM output": the model wraps its answer in ```markdown fences. Reported across GPT-4o, Claude, Llama, and Mistral. The workaround is a Code node that strips backticks before parsing
n8n Text ClassifierJeffy
Reliability JSON parse failures in production Deterministic, always valid JSON
Latency 500ms – 3s per item ~15ms local, ~300ms remote
Cost LLM API credits per call Free (self-hosted or playground)
API key Required (OpenAI, Anthropic, etc.) Optional, public playground works
Setup Configure LLM + write category descriptions Pick a task from the dropdown
Privacy Data sent to LLM provider Self-hostable, data stays local

On n8n Cloud? Cloud only allows installing verified community nodes, so steps 1 to 3 above apply to self-hosted n8n. On Cloud, use an HTTP Request node instead, which works identically:

Method POST, URL https://playground.jeffyclassify.com/v1/predict, JSON body:
{ "text": "{{ $json.message }}", "task": "banking77" }

The response carries label, confidence, margin and probabilities, so you can branch on it with a Switch or IF node exactly as with the node. There's a ready-made Cloud workflow below

Self-host or use the playground

The community node defaults to playground.jeffyclassify.com, a free public instance with 70+ classifiers loaded. No API key, no signup

For production, self-host Jeffy on any machine with a CPU: 

$ pip install jeffy-classify
$ jeffy serve --port 8400

Then point the n8n credential to http://localhost:8400. Your data never leaves your network

What's next

The node supports four operations: classify single text, batch classify, list available tasks, and health check. Batch sends an array in one request, useful for spreadsheet imports or email batches

If you're hitting reliability issues with the built-in Text Classifier, this is a drop-in replacement that won't surprise you at 3am
