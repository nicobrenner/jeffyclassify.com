Accuracy vs. speed

Every model on two axes at once. Up is more accurate, left is faster, so the top-left corner is where you want to be. Latency is a log scale, because the spread runs from a tenth of a millisecond to seventeen seconds.

Read the corners. FastText and SetFit sit far left and low: fast and wrong. The big LLMs sit far right: slow, and on 77 classes not even accurate. Jev is the only thing close to Jeffy on both axes, and it is a hosted API, so your text leaves your machine and you pay per call.

Accuracy vs. number of classes

On binary sentiment (2 classes), Jev leads at 96%, with LLMs and GLiNER close behind. By 4 classes Jeffy pulls ahead. At 77, everything else collapses.

The crossover: Between 2 and 4 classes, Jeffy overtakes all 15 competitors. By 77 classes, even Jev — the leading hosted decision model — scores 80% vs Jeffy's 94%. Open-source decision models fare worse: GLiNER 56%, Laya 38%. SetFit drops to 54%. FastText barely registers at 1%.

Run it yourself

JeffyBench is a reproducible benchmark. Clone the repo, install, and verify every number.

# Install Jeffy
pip install jeffy-classify datasets

# Pull the LLM you want to test
ollama pull phi4

# Run the full benchmark
python benchmarks/jeffybench.py --models phi4,mistral,llama3.1

# Or test on a single task
python benchmarks/jeffybench.py --tasks banking77 --models phi4

# Results are printed as tables and saved to JSON
